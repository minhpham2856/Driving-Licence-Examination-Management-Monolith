# Use Case Specifications: Examiner Portal

This document contains the detailed Business Analyst (BA) oriented Use Case (UC) specification tables for all Use Cases related to the **Examiner** role, as defined in the Examiner Use Cases diagram. These specifications are written in a clean, non-technical manner (free of URL paths, HTTP methods, servlet names, or code references) to focus purely on the business rules and user-system interactions.

---

### UC-01: Call candidates

| ID and Name       | UC-01 (Call candidates)                                                                                                                                                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Created By        | Pham Nhat Minh                                                                                                                                                                                                                                                               |
| Primary Actor     | Examiner                                                                                                                                                                                                                                                                     |
| Secondary Actors  | Candidate                                                                                                                                                                                                                                                                    |
| Description       | As an Examiner, I want to call a candidate using the call-board action list so that the candidate is broadcasted on the public display and notified to report to the testing area.                                                                                           |
| Trigger           | Examiner clicks the "Gọi thi" button next to a candidate's record.                                                                                                                                                                                                           |
| Preconditions     | PRE-1: Examiner must be logged in and have an active exam session.<br>PRE-2: Candidate is currently in the queue with an eligible status.<br>PRE-3: Database connection is available.                                                                                       |
| Postconditions    | POST-1: Candidate's call status is set to active in the database.<br>POST-2: Candidate is broadcasted on the waiting room public display screen.                                                                                                                             |
| Normal Flow       | 1.0. Call candidates<br><br>1. Examiner opens the actions page.<br>2. System loads candidate list with action buttons including "Gọi thi" for eligible candidates.<br>3. System displays flash message to notify examiner of action which has been done.<br>7. System ends use case. |
| Alternative Flows | 1.1 Search candidate<br><br>1. At step 2, Examiner inputs search query in the search bar.<br>2. System filters candidate list matching query.<br>3. Use case resumes at step 3 of normal flow.                                                                                |
| Exceptions        | 1.0.E1 Active exam session missing at step 2<br><br>1. System checks that no active exam is assigned to the examiner.<br>2. System displays warning message to select an active exam.<br>3. System ends use case.                                                            |

### UC-03: Suspend candidate

| ID and Name       | UC-03 (Suspend candidate)                                                                                                                                                                                                                                                    |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Created By        | Pham Nhat Minh                                                                                                                                                                                                                                                               |
| Primary Actor     | Examiner                                                                                                                                                                                                                                                                     |
| Secondary Actors  | None                                                                                                                                                                                                                                                                         |
| Description       | As an Examiner, I want to suspend a candidate who violates exam regulations using the violations panel so that they are disqualified from the exam.                                                                                                                         |
| Trigger           | Examiner decides to suspend a candidate for cheating or other rules violations.                                                                                                                                                                                              |
| Preconditions     | PRE-1: Examiner must be logged in and have an active exam session.<br>PRE-2: Candidate is currently participating in the session.<br>PRE-3: Database connection is available.                                                                                               |
| Postconditions    | POST-1: Candidate's profile is flagged as suspended in the database.<br>POST-2: Candidate is removed from all queues and any bound device/vehicle is released.<br>POST-3: Violation record with evidence details is created in the database.                                 |
| Normal Flow       | 3.0. Suspend candidate<br><br>1. Examiner opens the violations page.<br>2. System loads candidate list and displays current exam statuses.<br>3. Examiner selects candidate and triggers "Đình chỉ" (Suspend) action.<br>4. System prompts for suspension details, invoking UC-03a (Provide reason) and UC-03b (Upload evidence image).<br>5. System requests verification of examiner identity, invoking UC-03c (Verify password).<br>6. Examiner submits the violation details.<br>7. System updates candidate status to suspended, registers violation record, and releases device/queues.<br>8. System displays flash message to notify examiner of action which has been done.<br>9. System ends use case. |
| Alternative Flows | 3.1 One-click quick suspend<br><br>1. At step 3, Examiner clicks "Quick Suspend" next to candidate row.<br>2. System updates candidate status to suspended directly in database (no detailed reasoning or file uploaded).<br>3. System ends use case.<br><br>3.2 Revert suspension<br><br>1. At step 2, Examiner selects a candidate currently suspended.<br>2. Examiner clicks "Hủy đình chỉ" (Undo Suspend) button.<br>3. System clears suspended flag for the candidate in the database.<br>4. System displays flash message to notify examiner of action which has been done.<br>5. System ends use case. |
| Exceptions        | 3.0.E1 Evidence file invalid at step 5<br><br>1. At step 5, system validates uploaded evidence file size or format.<br>2. If invalid, system displays error message indicating the file exceeds limit or has invalid extension.<br>3. System ends use case.                  |
