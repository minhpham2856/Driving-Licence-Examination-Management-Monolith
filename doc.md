3.6 Examiner pages

3.6.1 General examiner functions

3.6.1.1 Exam selection

This screen allows the Examiner to:
View all examination sessions assigned to him/her.
View the code, date, time, licence class, and status of each assigned examination.
Select an examination session to activate as the working context.
Identify which examination is currently active.
On the screen, s/he can also:
Refresh the list of assigned examinations.
Open the Examiner Dashboard after selecting an examination.
View a safe empty state when no examination has been assigned.
Field Description

| Field Name | Description |
| --- | --- |
| Exam Code | Displays the unique code of the assigned examination session. |
| Exam Date | Displays the date on which the examination takes place. |
| Start / End Time | Displays the scheduled start and end time of the examination. |
| Licence Class | Displays the driving licence class of the examination (A1, A, B1, …). |
| Exam Status | Displays the current status of the examination, such as Not Started, In Progress, or Finished. |
| Section | Displays the section (Theory or Practical) the Examiner is assigned to supervise. |
| Select | Activates the selected examination as the Examiner's working session. |
| No Assignment | Displays a safe empty-state message when the Examiner has no assigned examination. |

3.6.1.2 Examiner dashboard

This screen allows the Examiner to:
View a summary of the active examination on a single line (exam code, date, licence class).
View candidate statistics: total, present, absent, completed, and suspended.
Monitor the overall progress of the examination session.
Navigate to the Action Board, Candidate List, Devices, Documents, and Audit pages.
On the screen, s/he can also:
Refresh the dashboard statistics.
Switch to another assigned examination via the Exam Selection screen.
Field Description

| Field Name | Description |
| --- | --- |
| Exam Code | Displays the code of the currently active examination. |
| Exam Date | Displays the date of the active examination. |
| Licence Class | Displays the licence class of the active examination. |
| Total Candidates | Displays the total number of candidates enrolled in the examination. |
| Present | Displays the number of candidates who have checked in. |
| Absent | Displays the number of candidates marked as absent. |
| Completed | Displays the number of candidates who have finished their section. |
| Suspended | Displays the number of candidates suspended from the examination. |
| Candidate Table | Displays the candidate list with candidate number, full name, status, and score. |

3.6.1.3 Candidate list

This screen allows the Examiner to:
View the full list of candidates of the active examination.
View each candidate's number, name, status, and score.
Open the details page of a selected candidate.
On the screen, s/he can also:
Search candidates by candidate number, name, or government ID.
Print candidate information, the candidate list, or the result list.
Refresh the candidate list.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number (SBD) | Displays the candidate's examination number. |
| Full Name | Displays the candidate's full name. |
| Status | Displays the candidate's current examination status. |
| Score | Displays the candidate's score; empty when not yet available. |
| Details | Opens the Candidate Details page for the selected candidate. |
| Print Info / List / Result | Prints candidate information, the candidate list, or the result list. |
| Search | Filters the candidate list by candidate number, name, or government ID. |

3.6.1.4 Candidate details

This screen allows the Examiner to:
View the personal information of a candidate: full name, date of birth, sex, government ID, phone, email, and address.
View the candidate's portrait photo.
View the candidate's examination information: candidate number, licence class, sections taken, and attempt number.
View the candidate's status and result within the active examination.
On the screen, s/he can also:
Navigate back to the candidate list.
Open the theory paper or the result editor of the candidate when applicable.
Field Description

| Field Name | Description |
| --- | --- |
| Photo | Displays the candidate's portrait photo. |
| Full Name | Displays the candidate's full name. |
| Date of Birth | Displays the candidate's date of birth. |
| Sex | Displays the candidate's sex. |
| Government ID | Displays the candidate's government identification number. |
| Phone / Email / Address | Displays the candidate's contact information; empty when not provided. |
| Candidate Number | Displays the candidate's examination number. |
| Licence Class | Displays the licence class the candidate is taking. |
| Sections | Displays whether the candidate takes the theory and/or practical section. |
| Attempt Number | Displays which attempt this examination is for the candidate. |
| Status | Displays the candidate's current examination status. |

3.6.2 Examination controls

3.6.2.1 Action board

This screen allows the Examiner to:
View the list of candidates of the active section with their statuses and scores.
Record attendance by marking a candidate as present.
Undo attendance for a candidate who has not started the examination yet.
Receive an alert when attendance cannot be undone because the candidate is taking the examination, awaiting signature, or has completed the section.
Call a candidate to the examination position.
Suspend a candidate by opening the Suspension form.
Open the score entry page for a practical candidate.
Finish a candidate's result after grading is complete.
Edit a completed practical result through the deduction-based editor.
Print the result record of a completed candidate.
On the screen, s/he can also:
Search candidates by candidate number, name, or government ID.
Refresh the candidate list.
View success or error messages after each action.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number (SBD) | Displays the candidate's examination number. |
| Full Name | Displays the candidate's full name. |
| Status | Displays the candidate status, such as Not Taken, Present, In Progress, Awaiting Signature, Completed, Absent, or Suspended. |
| Score | Displays the candidate's current score; empty when no score is available. |
| Attendance | Marks the candidate as present, or undoes attendance when still allowed. |
| Call | Calls the candidate to the examination position. |
| Suspend | Opens the Suspension form for the candidate. |
| Enter Score | Opens the practical score entry page for the candidate. |
| Complete | Finalizes the candidate's result for the section. |
| Edit Result | Opens the deduction-based result editor for a completed practical candidate. |
| Print | Prints the candidate's result record. |
| Search | Filters the candidate list by candidate number, name, or government ID. |

3.6.2.2 Practical score entry

This screen allows the Examiner to:
View the candidate being graded, including candidate number, name, and section.
View the list of fault criteria of the practical section.
Increase or decrease the occurrence count of each fault.
View the current score calculated in real time from the recorded faults.
Save the recorded score for the candidate.
Finish the candidate's practical section after grading.
On the screen, s/he can also:
Print the practical result record when eligible.
View success or error messages after saving.
Navigate back to the Action Board.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number / Name | Displays the identity of the candidate being graded. |
| Fault Reason | Displays the description of each fault criterion. |
| Points | Displays the number of points deducted per occurrence of the fault. |
| Occurrence | Displays and adjusts (+/-) how many times the fault occurred. |
| Critical Fault | Indicates a fault that causes automatic failure. |
| Current Score | Displays the score computed from 100 minus all recorded deductions. |
| Save Score | Persists the recorded faults and score for the candidate. |
| Complete | Finalizes the candidate's practical section. |
| Print | Prints the practical result record. |

3.6.2.3 Edit practical result

This screen allows the Examiner to:
View the completed practical result of a candidate.
Adjust fault occurrences with +/- controls instead of typing a score manually.
View the old score and the newly calculated score side by side before saving.
Provide a reason for the score change.
Confirm the change with his/her account password.
On the screen, s/he can also:
Cancel and navigate back to the Action Board.
View an error message when the password is incorrect or the edit is not allowed.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number / Name | Displays the identity of the candidate whose result is edited. |
| Fault List | Displays all fault criteria with adjustable occurrence counts. |
| Old Score | Displays the score recorded before the edit. |
| New Score | Displays the recalculated score based on the adjusted faults. |
| Reason | Requires the reason for editing the result, which is written to the audit log. |
| Confirm Password | Requires the Examiner's password to authorize the change. |
| Save | Applies the new score and writes an audit entry with old and new values. |

3.6.2.4 Candidate suspension

This screen allows the Examiner to:
Suspend a candidate from the examination for a serious violation.
Select the violation reason and enter a detailed description.
Upload an evidence image of the violation.
Confirm the suspension with his/her account password.
On the screen, s/he can also:
Cancel and navigate back to the Action Board.
View an error message when the password is incorrect or required fields are missing.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number / Name | Displays the identity of the candidate being suspended. |
| Licence Class | Displays the candidate's licence class; empty when not available. |
| Violation Reason | Selects the reason for the suspension. |
| Details | Enters the detailed description of the violation. |
| Evidence Image | Uploads the mandatory image evidence of the violation. |
| Confirm Password | Requires the Examiner's password to authorize the suspension. |
| Suspend | Submits the suspension and records the violation. |

3.6.2.5 Candidate theory paper

This screen allows the Examiner to:
View the candidate's theory paper with all questions and chosen answers.
View which answers are correct or incorrect.
View the calculated theory score and the pass/fail outcome.
On the screen, s/he can also:
Navigate back to the candidate list or the Action Board.
Print the theory result record.
Field Description

| Field Name | Description |
| --- | --- |
| Candidate Number / Name | Displays the identity of the candidate whose paper is shown. |
| Question | Displays each question of the theory paper. |
| Chosen Answer | Displays the answer selected by the candidate. |
| Correct Answer | Displays the correct answer for comparison. |
| Critical Question | Indicates a critical question that causes automatic failure when answered incorrectly. |
| Score | Displays the total theory score. |
| Result | Displays the pass/fail outcome of the theory section. |
